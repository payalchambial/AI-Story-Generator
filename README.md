# AI-Story-Generator
An AI-powered application that generates creative stories from user-provided ideas or prompts. It uses Generative AI to create engaging story content and can transform stories into a more interactive multimedia experience.
Key Features:

✨ AI-generated stories from simple prompts
🖼️ Story image generation
🎙️ AI voice narration
🎬 Multimedia story creation
🖥️ Interactive Streamlit interface
🤗 Hugging Face integration
🧠 Generative AI and LLM-based processing

Technologies Used:
Python, Streamlit, Generative AI, LLMs, Hugging Face, NLP, Text-to-Speech

The purpose of the AI Story Generator is to make storytelling easier, faster, and more creative by using Generative AI. It allows users to provide a simple idea or prompt and automatically generates a complete story.

The project also aims to create an engaging multimedia experience by combining **AI-generated text, images, and voice narration** in one application. It demonstrates the practical use of **Generative AI, LLMs, NLP, and AI-based content generation**.
